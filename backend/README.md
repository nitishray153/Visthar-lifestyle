# Visthar Lifestyle Backend

Production-oriented Node.js + Express + MongoDB backend with MVC architecture.

## Setup
1. Copy `.env.example` to `.env` and fill secrets.
2. Install dependencies: `npm install`
3. Run dev server: `npm run dev`

## Routes
- `/api/auth`
- `/api/users`
- `/api/products`
- `/api/cart`
- `/api/orders`
- `/api/reviews`
- `/api/upload`
- `/api/admin`
